# Виведення файлів та піддиректорій

## Опис

Ця програма написана на мові програмування Python та призначена для виведення всіх файлів і піддиректорій, які знаходяться в поточній робочій директорії.

Програма використовує стандартний модуль `os`, який дозволяє працювати з файловою системою.

## Функціонал

* Виведення файлів поточної робочої директорії.
* Виведення піддиректорій поточної робочої директорії.
* Рекурсивний перегляд вкладених папок (у другому варіанті коду).

## Використані технології

* **Python 3**
* **Модуль os** — для роботи з файлами та директоріями.

## Встановлення та запуск

### 1. Перевірка встановлення Python

Переконайтеся, що на вашому комп'ютері встановлено Python 3.

Перевірити версію можна за допомогою команди:

```bash
python --version
```

### 2. Створення файлу

Створіть файл із назвою `main.py` та додайте до нього код:

```python
import os

for item in os.listdir('.'):
    print(item)
```

### 3. Запуск програми

Відкрийте термінал у папці з файлом і виконайте:

```bash
python main.py
```

## Приклад результату

```text
main.py
README.md
documents
images
```

Результат залежить від вмісту поточної робочої директорії.

## Рекурсивний перегляд

Для виведення файлів і піддиректорій у всіх вкладених папках використовується `os.walk()`:

```python
import os

for root, dirs, files in os.walk('.'):
    for directory in dirs:
        print(os.path.join(root, directory))
    for file in files:
        print(os.path.join(root, file))
```
